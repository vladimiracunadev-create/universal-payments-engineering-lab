## Regla editorial

Cada afirmación se clasifica como hecho verificable del repositorio, explicación de industria respaldada por una fuente primaria o decisión que debe validarse contra el contrato vigente del proveedor. Las marcas se usan solo para describir ecosistemas; no existe afiliación ni certificación implícita.
