# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Se espera una colaboración respetuosa, inclusiva, profesional y enfocada en evidencia.

Conducta inaceptable incluye acoso, discriminación, publicación de información privada, pruebas financieras no autorizadas, exposición de credenciales o presión para ocultar riesgos/limitaciones. Reporta incidentes mediante los canales privados disponibles en el perfil del mantenedor; no publiques datos sensibles en issues.
